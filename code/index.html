Quantum Gate Music Generator

An archive of the GUI and five musical generation modes documented on the original Quantum Creation website.

Source code and interface

The original research website describes a Python/Qiskit graphical interface for configuring quantum gates, running measurements, and translating their outcomes into musical sequences. It includes five selectable modes. The screenshots below are archived from the original website.

Original GitHub source repository ↗ Original Code page ↗

This is the earlier Quantum Gate Music Generator, distinct from the later web-based two-player Quantum-Game Dual Synth.

Graphical interface

The bottom output panel shows measured bitstrings. The rightmost bit represents the earliest note in time; each row is a distinct result among the measurement shots.

Mode 1 · Stochastic note generation

One qubit represents each note. The user chooses a measurement-axis setting, and a chain of CNOT gates connects successive time steps. Measurements select notes probabilistically; multiple shots can produce different note sequences.

Mode 2 · Pitch and duration

Two qubits represent each note: one for note duration (quarter note or half note) and one for pitch. CNOT links along the sequence introduce correlations between pitch and duration.

Mode 3 · Chord generation

Three qubits encode pitches using a mapping based on the circle of fifths. Quantum states are configured to represent notes belonging to diatonic chords, and measurement selects individual notes. The original site illustrates a I–ii–V–I chord progression.

Mode 4 · Quantum phrase modulation

A specified pitch sequence is encoded using three-qubit states. Quantum-gate operations between neighboring notes modify the resulting possibilities coherently before measurement, allowing probabilistic variations of the original phrase.

Mode 5 · Two-player quantum-game model

Two players select measurement strategies after their note states have been entangled. Their choices jointly influence the distribution of measured musical outcomes. This is the quantum-game mode of the earlier GUI, not a screenshot of the 2025 web demonstration.

See also the separate 2025 two-player interactive music project.
