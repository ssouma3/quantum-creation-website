Quantum Live Coding

Live musical performance using simulated quantum states and gate operations.

Quantum states as musical parameters

The wavefunction-based approach maps parameters of simulated qubit states onto musical expressions. In the published example, the Bloch-sphere azimuth φ corresponds to notes within an octave, while the polar angle θ represents octave shifts. Continuous φ values also make microtonal pitches possible.

Live coding and performance

Quantum-gate operations are written and executed in a live-coding environment, changing the simulated state and thus the generated sound. Bloch spheres and circuit diagrams are updated in real time. The work distinguishes note qubits from observation qubits and explores musical changes associated with entanglement between them.

Implementation

The published prototype uses FoxDot and SuperCollider for live coding and sound, QuTiP for Bloch-sphere visualization, and Tkinter for circuit diagrams. This approach relies on simulator-accessible wavefunction information; the paper does not present it as a live hardware measurement system.
