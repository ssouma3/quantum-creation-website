量子ゲート音楽生成プログラム

旧Quantum Creationサイトに掲載されていたGUIと、5つの音楽生成モードの概要

ソースコードと操作画面

旧研究サイトでは、PythonとQiskitを利用し、量子ゲートの設定、測定、測定結果に基づく音列生成を行うGUIを紹介しています。5つのモードを備え、以下に掲載する図は旧サイトから回収したものです。

旧サイトで紹介されているGitHubコード ↗ 旧Codeページ ↗

このプログラムは、後に開発されたWebベースのQuantum-Game Dual Synthとは別のものです。

GUIの概要

画面下部には測定ビット列が表示されます。右端のビットが時間的に最初の音に対応し、各行には測定結果が表示されます。

Mode 1 · 確率的音列生成

1音を1量子ビットで表現し、測定軸を指定して音高を確率的に決める方式です。時間方向の量子ビットをCNOTゲートで結び、複数回の測定から異なる音列を得られます。

Mode 2 · 音高と音価

1音を2量子ビットで表し、音価（四分音符・二分音符）と音高を扱います。時間方向のCNOT接続により、音高と音価の間にも量子的な相関を導入します。

Mode 3 · コード生成

3量子ビットを用い、五度圏に基づいて音高を符号化します。ダイアトニックコードの構成音に対応する量子状態を準備し、測定によって音を選びます。旧サイトでは I–ii–V–I のコード進行を例示しています。

Mode 4 · 量子フレーズ変調

指定した音列を3量子ビットの状態として準備し、隣接する音の間に量子ゲートによる変調を加えます。測定前の量子状態における操作を通じて、元のフレーズから確率的に変化した音列を生成します。

Mode 5 · 量子ゲーム理論に基づく2人演奏モデル

2人の音の量子状態をもつれさせ、各演奏者が測定戦略を選びます。両者の選択が測定結果の確率分布に関係することで、相互作用を音楽生成に取り入れるモデルです。ここに掲載するのは初期のGUIの図であり、2025年のWebデモの画面ではありません。

別途、2025年の2人用インタラクティブ音楽システムも紹介しています。
